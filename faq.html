❓ Frequently Asked Questions

• How do I add a game to ICEGames?

To add a game, upload your game file (such as .swf or HTML5 files) into the appropriate category folder on the server. Then create a new game page using our game template and link it from the homepage.

• Can I add Flash (.SWF) games?

Yes. ICEGames supports Flash games using the Ruffle emulator, allowing classic Flash titles to run safely in modern browsers.

• My game does not load. What should I check?

Make sure the game file path is correct, the file name matches exactly, and the game page includes the Ruffle loader. Also check the browser console for errors.

• The game is laggy or stretched. How do I fix this?

Try adjusting the game size, disabling background effects, or enabling fullscreen mode. On mobile devices, switching to landscape mode often helps.

• Some buttons or controls do not work.

Older Flash games may rely on deprecated features. If a control does not respond, try a different browser or refresh the page. Ruffle is still improving compatibility.

• How can I report a bug?

Use the Contact Us page and include: the game name, category, browser used, and a description of the issue.

• How can I support ICEGames?

You can support ICEGames by:

  • Sharing the website with friends
  • Submitting classic games or backups
  • Reporting bugs and broken games
  • Respecting original creators and copyrights

• Can I create my own ICEGames category?

Yes. Categories are fully customizable. Simply add a new category section to the homepage and link your games.

• Is ICEGames free to use?

Yes. ICEGames is completely free and always will be. Our mission is preservation, not profit.

• Will ICEGames add multiplayer or accounts?

Multiplayer and user accounts are planned features. Support and feedback from users helps prioritize development.

• Why does ICEGames exist?

ICEGames exists to preserve the history of browser games, honor the Flash era, and keep classic games playable for future generations.
